# GitHub Crypto Oracle Bot

Bot público que responde a issues con arte ASCII, chistes y frases zen.
Desbloquea profecías premium con pago en ETH verificado on-chain vía Etherscan.

## Uso
1. Abre un issue → el Oracle responde gratis (arte ASCII + chiste + frase zen).
2. Comenta lo que quieras → el Oracle susurra.
3. Envía **0.50 USD en ETH** a `0xA5E6eB31868A85127B1ED82b8C760193356206ED` y comenta `/premium <tx_hash>` → profecía premium verificada on-chain.
